
# 💰 Controle Financeiro em Python

## Sobre o projeto

Este projeto consiste em um sistema de controle financeiro desenvolvido em Python, com o objetivo de praticar lógica de programação e manipulação de dados.

A aplicação permite registrar e administrar despesas por meio de um menu interativo.

## Funcionalidades

- Cadastrar despesas;
- Consultar despesas cadastradas;
- Excluir despesas;
- Calcular o total de gastos;
- Gerar relatório financeiro.

## Tecnologias utilizadas

- Python
- Google Colab
- Arquivos CSV

## Aprendizados

Durante o desenvolvimento, pratiquei:

- Variáveis e estruturas condicionais;
- Estruturas de repetição;
- Funções;
- Listas e dicionários;
- Manipulação de arquivos;
- Leitura e gravação de arquivos CSV;
- Tratamento de erros.
